# 🚀 Express Tech-Blog Engine

A robust Full-Stack application built with **Node.js** and **Express.js**. This project features a dual-interface system where users can read technical blogs via a Web UI or fetch raw data through a professional REST API.

🚀 **Live Site:** [Visit Blog UI](https://express-blog-project-production-a2eb.up.railway.app)  
💻 **GitHub Repo:** [View Source Code](https://github.com/rabiamuhammadsaleem/express-blog-project)

---

## ✨ Features

- **Hybrid Interface:** Supports both Server-Side Rendering (SSR) for browsers and JSON responses for API clients.
- **Comprehensive Tech Topics:** In-depth blogs on JWT, Mongoose, Bcrypt, MVC, and more.
- **RESTful API:** Dedicated POST endpoint for developer testing.
- **Clean Architecture:** Built using the MVC (Model-View-Controller) pattern.
- **Responsive Design:** Optimized for all screen sizes.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose)
- **Deployment:** Railway
- **Security:** Bcrypt (Hashing), JWT Concepts

---

## 📮 API Documentation (Postman Testing)

Developers can test the backend API using the following configuration:

### ✨**Common Settings:**
- **URL:** `https://express-blog-project-production-a2eb.up.railway.app/api/blog`
- **Method:** `POST`
- **Headers:** `Content-Type: application/json`

### **Request Body Example (Raw JSON):**

{
  "topic": "mongoose"
}


### **Supported Topics:**
jwt, mongoose, bcrypt, serversiderendering, clientsiderendering, mvc, schema, middlewares.
